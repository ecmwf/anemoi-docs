This directory contains a collection of files used by agentic coding harnesses. These files should contain instructions that are common to all `anemoi` repositories.

When modified these files will be "broadcasted" (i.e. copied) to the various anemoi repositories as pull requests in these repos.

The `AGENTS.md` (a.k.a `CLAUDE.md`) is common to all repos. For repo specific system prompts, use `AGENTS-local.md`.
